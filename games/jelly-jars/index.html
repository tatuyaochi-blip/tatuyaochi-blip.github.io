🫙 Jelly Jars

Open in new tab

Pour jelly between jars until every jar holds a single color.

About the game

Jelly Jars is a calm color sorting puzzle. Tap a jar, then tap another to pour the top jelly across. Jelly can only land on the same color or in an empty jar, and each jar holds four. Plan ahead to sort every color into its own jar. Levels start easy and grow to twelve colors. Each color also has its own symbol, so you can play without telling colors apart. Stuck? Undo, add one extra jar, or ask for a hint. A daily puzzle gives everyone the same jars.

How to play

Tap or click a jar, then tap the jar to pour into. Keyboard: number keys pick jars, arrow keys move, Enter selects, Z undo, R restart, H hint.
